# Frontend rules
Use generated API hooks and artifact-relative URLs. Show backend errors and source
unknowns explicitly. Never turn uncertain graph edges into confirmed dependencies
or sample measurements into upload validation. AI controls remain unchecked and
must explain external source transmission and credit billing. Preserve keyboard
access and responsive tables. Invalidate analysis/report/list queries after writes;
do not rewrite immutable earlier simulation snapshots. Keep stable test IDs for
the critical workflow.
