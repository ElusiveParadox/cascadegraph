# Contributing
Start with AGENTS.md, architecture, semantics and limitations. Open a focused
feature PR. Include expected behavior, source fixtures, tests, security implications
and documentation changes. Keep unsupported constructs visibly unresolved.
Run the frozen-lockfile local checks and wait for all required GitHub checks.
Never commit credentials, uploads, database files or build/measurement artifacts.
Do not modify the trusted-validation bundle from user-supplied data.
